01 / THE ESSENTIALS

A model is the engine.
Ollama helps you run it.

Ollama is software for downloading and running AI models on your computer. Choose a model, download its files, then use it through Ollama’s app, command line, or local API.

For the local models in this guide, inference happens on your computer. Installation and model downloads need internet access; after downloading, local inference can work offline. Cloud models, web search, and connected tools have different network behavior. This guide recommends local variants.

You don’t need to learn everything first. Start with a small model and a simple task. Use the glossary when a new term comes up.

04 / YOUR FIRST CONVERSATION

Useful commands

/bye exits the interactive conversation. Slash commands go inside Ollama’s chat; commands beginning with ollama go in your terminal.

Images, embeddings, and media

Image-understanding models accept a picture plus a prompt; they are not necessarily image generators. In supported Ollama CLI workflows, include an absolute image path with your prompt. Verify the selected model’s capabilities first.

Embedding models turn text into numerical vectors for search and retrieval. They do not reply like a chatbot. The personalized guide uses Ollama’s local embedding API for these models; building a search app requires additional code.

Audio, video, music, and image-generation tasks have no verified direct match in this catalog. A text model can help write a script or caption text, but cannot thereby process or generate the media itself.

06 / MAKING ROOM FOR THE MODEL

Planning estimates, clearly labeled.

There is no universal minimum computer for a model family. These estimates apply to one exact quantized variant, one running model, one user, and the stated context limit. They do not guarantee performance, stability, or thermal safety.

Download sizes and model capabilities come from linked sources. Memory budgets and recommendation rules are editorial estimates. GPU compatibility also depends on your exact device, driver, operating system, and Ollama version. We never combine dedicated RAM and VRAM into one memory pool.

Our task matcher uses visible categories and simple keyword rules. Results are not benchmark rankings or promises that a model will solve your task correctly.
